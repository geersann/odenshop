# Odor-Free Home Pro

Independent deployment version of the one-page Ukrainian landing page for a silicone sewer odor-blocking valve.

## Stack

- React 19
- TanStack Start
- Vite
- Cloudflare Workers
- Telegram Bot API for order notifications

The application does not require Lovable at runtime.

## Local development

```bash
npm install
npm run dev
```
